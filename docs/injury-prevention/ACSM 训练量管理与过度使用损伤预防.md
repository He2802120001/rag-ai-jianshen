# 常见过度使用损伤的预防

> 本文为一般性科普，不构成医疗建议。

## 预防性内容
- 循序渐进增加训练量，常见经验是每周增幅不超过 10% 左右。
- 合理安排推拉平衡，避免单一动作模式重复过多。
- 关注肩、肘、膝的早期不适信号，及时调整训练量。
- 交替安排高强度与低强度训练日。

## 与治疗的分界
- 出现持续疼痛、肿胀或活动受限，应停止相关训练并咨询医生或康复师。
- 本文不提供具体伤病的诊断或治疗方案。
