# 划船

## 动作要领
- 以俯身杠铃划船为例：屈髋俯身，腰背中立，杠铃自然下垂。
- 肩胛骨先后缩，再屈肘将杠铃拉向腹部。
- 拉至顶峰时肘部贴近身体，避免耸肩。
- 下放控制，保持躯干稳定不晃动。

## 常见错误
- 躯干起伏借力：提示重量过大或核心未收紧。
- 耸肩代偿：应先建立肩胛下沉后缩模式。
- 只用手臂拉、肩胛不动：削弱背部训练效果。
- 腰背圆曲：应降低重量并检查髋铰链模式。

## 适用人群与禁忌
- 适合大多数健康成年人。
- 禁忌与需谨慎的情况：急性腰背疼痛、肩关节急性疼痛。出现疼痛应停止并咨询专业人士。
- 特殊人群不在本文范围内。

## 替代动作
- 坐姿绳索划船：减少腰部负荷。
- 单臂哑铃划船：单侧控制更好。
- 反向划船：自重替代。
