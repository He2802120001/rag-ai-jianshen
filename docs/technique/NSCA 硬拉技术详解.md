# 硬拉

## 动作要领
- 杠铃位于足中线上方，小腿距杠约 2 到 3 厘米。
- 屈髋屈膝抓杠，肩胛骨位于杠铃正上方或略前，腰背保持中立。
- 起拉时先建立腹压，腿部发力推地，杠铃贴近小腿和大腿上行。
- 锁定时刻意收紧臀部，避免腰椎过度后伸。

## 常见错误
- 起拉时臀部先抬、腰部代偿：提示起始髋位过低或核心未建立腹压。
- 杠铃远离身体：增加腰部力矩，应让杠铃贴身上行。
- 锁定阶段腰椎过伸：应靠臀肌完成锁定，而非后仰。
- 圆背起拉：重量过大或动作模式未建立，应降重量练习。

## 适用人群与禁忌
- 适合具备基础动作模式、无急性腰背疼痛的健康成年人。
- 禁忌与需谨慎的情况：急性腰痛、未控制的腰椎间盘突出症状、严重高血压未控制者。出现疼痛应停止并咨询专业人士。
- 特殊人群（孕期、心血管疾病、术后）不在本文范围内。

## 替代动作
- 六角杠硬拉：减少腰部力矩，适合初学者或腰背敏感者。
- 罗马尼亚硬拉：侧重后链，重量较轻。
- 壶铃硬拉：学习髋铰链模式。
