# 肩推

## 动作要领
- 站姿或坐姿，杠铃置于锁骨前方，握距略宽于肩。
- 收紧核心与臀部，避免腰椎过度后伸。
- 垂直向上推起，头部略后让出杠铃路径，锁定后杠铃位于头顶正上方。
- 下放控制至锁骨前方。

## 常见错误
- 腰椎过度后伸代偿：核心未收紧或重量过大。
- 推起路径前移：应保持杠铃垂直上行。
- 肩胛未上回旋：影响肩关节空间，应先建立上举模式。
- 手腕过度后伸：保持手腕中立。

## 适用人群与禁忌
- 适合具备基础肩部活动度的健康成年人。
- 禁忌与需谨慎的情况：急性肩关节疼痛、肩峰撞击症状明显者、未控制的高血压。出现疼痛应停止并咨询专业人士。
- 特殊人群不在本文范围内。

## 替代动作
- 哑铃肩推：轨迹更自由。
- 地雷管推举：肩部压力相对可控。
- 侧平举：孤立三角肌中束。
