# 减脂期饮食原则

> 本文为一般性科普，不构成医疗或营养处方。

## 一般原则
- 减脂的核心是可持续的热量缺口，常见实践做法是每日缺口 300 到 500 千卡（此为常见实践建议，非单一指南强制标准）。
- 蛋白质摄入保持较高水平，有助于保留瘦体重；低热量饮食期间进行抗阻训练者，蛋白需求可能升高。
- 碳水不必完全戒断，可根据训练安排分配。
- 优先选择天然食物，保证蔬菜和膳食纤维摄入。

## 需谨慎的情况
- 疾病相关饮食、孕期和特殊人群的减脂方案需遵医嘱，本文不提供此类建议。
- 出现头晕、乏力等不适时应停止极端节食并咨询专业人士。
