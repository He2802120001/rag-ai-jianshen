# 蛋白质摄入的一般原则

> 本文为一般性科普，不构成医疗或营养处方。疾病相关饮食请咨询注册营养师或医生。

## 一般原则
- 有规律力量训练的成年人，常见建议范围为每公斤体重每天 1.4 到 2.0 克蛋白质（ISSN 立场声明）。
- 系统综述与 Meta 分析表明，蛋白质补充在约 1.62 g/kg/天以上不再进一步增加抗阻训练引起的瘦体重增长，并非越多越好。
- 蛋白质来源尽量多样：禽肉、鱼、蛋、奶、豆制品等。
- 分配到每餐有助于提高利用率，常见做法为单次 20 到 40 克（或约 0.25 g/kg）优质蛋白，每 3 到 4 小时分配一次。
- 训练后蛋白质窗口期并非严格"30 分钟内"，运动后合成代谢效应可持续较长时间，全天总摄入量比单次时机更重要。

## 需谨慎的情况
- 肾病、肝病等疾病人群的蛋白质摄入需遵医嘱，本文不提供此类建议。
- 使用蛋白粉前应确认无相关过敏或不耐受。
- 注意区分：一般人群的蛋白质推荐量（如膳食指南的每公斤 1.2 到 1.5 克）对应的是健康和康复场景，与训练人群的增肌推荐数值不同，不应混用。
