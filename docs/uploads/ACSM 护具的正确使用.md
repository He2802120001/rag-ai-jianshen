# 护具的正确使用

> 本文为一般性训练科普，不构成医疗建议。护具是辅助工具，不能替代动作技术与力量基础；伤后使用方案请遵医嘱。

## 各类护具的定位

- **腰带（举重腰带）**：通过增加腹内压提升躯干刚性，服务于大重量深蹲/硬拉（一般 ≥85% 1RM 再考虑），不是"护腰神器"——中小重量长期佩戴反而削弱自身核心参与；
- **护腕（缠绕式）**：为卧推、肩推提供腕部支撑，防止过度背伸；手腕有不适史者收益最大；
- **助力带（Straps）**：绕杠分担抓握负荷，用于硬拉、划船等背部容量训练，避免握力先于背部力竭；不影响硬拉整体安全性；
- **护膝/膝套（套膝）**：保暖与轻微弹性支撑，帮助膝关节在深蹲底部保持温度与本体感；缠绕式护膝另有弹射助力，属力量举装备；
- **举重鞋**：跟垫抬高改善踝背屈不足，帮助深蹲重心与深度，非必需但 Useful。

## 正确使用原则

- 先技术后护具：护具弥补末端短板，不能纠正糟糕的动作模式；
- 强度门槛：腰带、缠绕护膝留给真正的大重量组；日常组让身体自身结构工作；
- 松紧适度：护腕缠绕以"手腕可微动、不麻"为度；腰带收紧后仍能完成深呼吸加压；
- 助力带不用于极限硬拉测试：测最大力量时按规则（无助力）评估真实水平；
- 护具不遮疼痛：佩戴后不痛不代表问题消失，疼痛持续存在建议就医查明原因；
- 卫生与老化：织物类护具定期清洗，弹性材料（腰带衬垫、套膝橡胶）失去弹性即更换。

## 常见误区

- 新手全程系腰带做轻重量——核心参与不足，形成依赖；
- 用护腕硬撑已受伤的手腕继续大重量——把护具当治疗，延误就医；
- 助力带缠太死影响手腕位置——应只分担手指负荷，不锁死腕角。
