# 平板支撑

> 本文为一般性训练科普，不构成医疗建议。

## 动作要领

- 肘部位于肩正下方，前臂平行或双手交握，双脚与髋同宽或并拢；
- 头、肩、髋、踝呈一条直线，收腹夹臀，肋骨下压防止塌腰；
- 自然呼吸不憋气，目视地面略前方，颈椎中立；
- 以"能保持标准姿态的最长时间"为限，变形即停。

## 常见错误

- **塌腰**：腰椎代偿悬吊，腰部受压，核心刺激反而下降；
- **撅臀**：把支撑变成休息位，腹肌张力流失；
- **盲目追求时长**：超过 60-90 秒后多为耐力维持，质量优先于秒数；
- **憋气**：血压波动，应保持浅而稳的呼吸节奏。

## 适用人群与禁忌

- 适合几乎所有训练水平者作为核心抗伸展训练与热身动作；
- 孕期、腹直肌分离、近期腹部手术者不宜做俯卧支撑类动作；
- 高血压人群避免长时间憋气式支撑，分段短组更稳妥；
- 腕部不适者可用拳面或使用瑜伽垫缓冲前臂支撑。

## 替代动作

- 跪姿平板支撑：降低难度，适合入门；
- 侧平板支撑：转向腹斜肌与侧链稳定；
- 死虫式（Dead Bug）：仰位训练核心，腰背零压迫，适合康复期与新手。
