# 咖啡因与训练表现

> 本文为一般性营养科普，不构成医疗或营养处方。心血管疾病人群摄入咖啡因前请咨询医生。

## 科学原理

咖啡因主要通过拮抗腺苷受体抑制中枢疲劳感，降低主观用力感知（RPE），从而提升耐力表现、爆发力输出与专注度；对力量训练也有小幅但一致的增益。国际运动营养学会（ISSN）立场文件指出，每公斤体重 3-6mg 咖啡因即可改善多数运动表现。个体差异显著：快代谢型收益明显，慢代谢型可能收益小且更易心悸；长期高频使用会产生耐受，增益减弱。

## 具体建议

- 剂量：训练前 30-60 分钟摄入 3-6mg/kg（如 70kg 者 200-420mg）；新手从 100-150mg 起步测试反应；
- 来源：黑咖啡、浓茶、无糖咖啡因补剂均可；避免高糖"能量饮料"带来的额外热量；
- 时间：下午 2 点后尽量不摄入，防止影响睡眠（咖啡因半衰期约 5 小时）；
- 策略：不必每天用，把咖啡因留给关键训练日或比赛日，保持敏感度；
- 出现心悸、手抖、焦虑应减半剂量或停用；孕产期、高血压、心律问题人群请遵医嘱。
