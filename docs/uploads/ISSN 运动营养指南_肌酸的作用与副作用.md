# 肌酸的作用与副作用

> 本文为一般性营养科普，不构成医疗或营养处方。肾功能异常者使用任何补剂前请咨询医生。

## 科学原理

肌酸是体内自然存在的含氮有机酸，约 95% 储存于骨骼肌，与磷酸结合为磷酸肌酸，负责快速再生 ATP（无氧磷酸原系统供能）。补充一水肌酸可提升肌肉肌酸储量约 10-20%，从而增加短时高强度运动的做功能力、组间恢复速度，并通过细胞水合与训练量积累间接促进力量与肌肉增长。一水肌酸（Creatine Monohydrate）是研究最充分、性价比最高的形式，国际运动营养学会（ISSN）立场文件认为其在推荐剂量下对健康人群安全性良好。

## 具体建议

- 常规方案：每天 3-5g 一水肌酸，长期连续服用，无需冲击期；约 3-4 周达到饱和；
- 服用时间不严格，训练后随餐或与蛋白粉同服依从性更好；
- 充足饮水；体重增加 1-2kg 属正常的肌肉内水合效应，非脂肪增加；
- 少数人可能出现轻微胃肠不适，可随餐分次服用缓解；
- 选购时认准成分为"一水肌酸"的正规产品，警惕高价"新型肌酸"营销溢价。

## 可能的副作用与边界

- 常见：体重上升（水分）、偶发胃肠不适；
- 理论关注点：肾功能异常人群缺乏长期安全性数据——如已有肾脏疾病，请先咨询医生，不要自行使用；
- 任何补剂都不能替代均衡饮食与系统训练；出现持续不适应停止使用并就医。
