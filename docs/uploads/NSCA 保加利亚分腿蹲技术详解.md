# 保加利亚分腿蹲

> 本文为一般性训练科普，不构成医疗建议。

## 动作要领

- 后脚背或脚尖搭在凳上（约膝高），前脚向前迈出一大步，两腿间距保证下蹲时前膝不超过脚尖太多；
- 重心 80-90% 放在前腿，躯干微前倾（约 10-20 度）以增加臀部参与；
- 下蹲至前大腿至少与地面平行，前脚全脚掌踩实，膝盖与脚尖同向；
- 起身时以前腿发力，顶端不完全锁膝，保持张力连续。

## 常见错误

- **站位过窄**：前膝过度前冲，膝关节压力增大；
- **重心分给后腿太多**：变成"后腿拉伸"，前腿刺激不足；
- **躯干过度前倾或后仰**：失去平衡，腰部代偿；
- **步幅忽大忽小**：每组之间轨迹不一致，进步难以量化。

## 适用人群与禁忌

- 适合有一定深蹲基础、想强化单腿力量与平衡的训练者；
- 膝关节不适者可减小幅度（半程）或后脚垫高改为静态箭步蹲；
- 平衡能力弱的新手先扶墙或使用徒手版本建立稳定；
- 髋或膝有急性症状期间不建议训练，应先就医评估。

## 替代动作

- 哑铃箭步蹲（行走式或原地）：动态平衡要求更低；
- 哈克机/史密斯分腿蹲：轨迹固定，负荷可精确渐进；
- 腿举机单腿推：卸载平衡需求，专注腿部发力。
