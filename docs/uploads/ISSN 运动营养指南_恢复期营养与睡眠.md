# 恢复期营养与睡眠

> 本文为一般性营养科普，不构成医疗或营养处方。持续失眠请咨询医生。

## 科学原理

训练本身是"刺激"，肌肉增长与能力提升发生在恢复期。恢复的两个支柱：营养（蛋白质修复原料 + 碳水补充糖原）与睡眠（生长激素分泌高峰、神经恢复、记忆巩固）。研究表明睡眠不足会降低训练表现、增加疲劳感，并可能扰乱食欲激素（瘦素/胃饥饿素），让饮食控制更难执行；而训练后 24-48 小时内均匀摄入足量蛋白质，配合 7-9 小时睡眠，是恢复效率的关键组合。

## 具体建议

- 训练后一餐：30-40g 优质蛋白（鸡胸、鱼、蛋、乳清）+ 适量碳水（按训练量 0.5-1.2g/kg），不必迷信"30 分钟合成窗口"，全天总量更重要；
- 睡前可摄入缓释蛋白（如酪蛋白、酸奶、牛奶）支持夜间肌肉蛋白合成；
- 每日蛋白均匀分配到 3-5 餐（每餐 0.4g/kg 左右）优于集中一餐；
- 睡眠管理：固定作息、睡前 1 小时远离强光与手机、卧室凉爽黑暗；避免晚间大量咖啡因（下午 2 点后不建议）；
- 高强度训练日之后安排主动恢复（散步、拉伸），睡眠需求可能略增至 8-9 小时。
