# 肩峰撞击预防

> 本文仅讨论预防手段，不涉及任何治疗。若肩部上举时持续疼痛、夜间痛或无力，建议就医，由医生或康复师评估处理。

## 认识肩峰撞击

肩峰撞击指肩峰下空间内（肩袖肌腱与滑囊）在手臂上举时受到挤压，产生肩前外侧疼痛，常见于大量过顶动作（肩推、卧推抓杠、引体）人群。诱因通常并非"结构天生狭窄"，而是：肩袖肌力不足、肩胛稳定差（上回旋不足）、胸椎活动受限与训练量安排失衡的组合。

## 预防手段

- 肩袖优先强化：每周 2 次弹力带外旋（肘贴身）与俯身外旋，轻重量 15-20 次 × 3 组，把它当"刷牙级"基本功；
- 肩胛稳定训练：面拉（Face Pull）与肩胛仰卧上举（肩胛俯卧撑），改善上回旋与后倾能力；
- 胸椎活动度：泡沫轴胸椎伸展、门框胸肌拉伸，每次上肢训练前 2-3 分钟，给肩峰"腾空间"；
- 过顶动作技术：肩推时肋骨下压避免腰椎代偿、略收下巴、杠铃轨迹绕过下巴而非头绕杠；卧推时肩胛后缩下沉贴凳；
- 容量管理：过顶推类与侧平举类动作每周总组数控制在合理区间（各 6-10 组），疼痛敏感期以面拉与绳索外旋替代部分推举；
- 避免大重量直立划船与颈后推举：这两类动作对肩峰下空间不友好，可用面拉与坐姿推举替代。

## 预防与治疗的边界

本文不提供治疗方案。出现上举痛弧（60-120 度疼痛）、夜间患侧卧痛或力量明显下降时，说明已超出预防范畴，建议就医评估，明确肩袖状态后再制定恢复计划。
