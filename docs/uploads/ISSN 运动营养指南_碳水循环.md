# 碳水循环

> 本文为一般性营养科普，不构成医疗或营养处方。疾病相关饮食请咨询注册营养师或医生。

## 科学原理

碳水循环（Carb Cycling）指按训练负荷高低安排每日碳水化合物摄入量：训练日高碳水以支撑训练强度与糖原补充，休息日低碳水让总热量更接近减脂缺口。其底层逻辑是"能量分期"——把较多的可利用能量放在最需要的时候，同时保持周期性的总热量缺口。研究表明，减脂的核心决定因素仍是长期总热量平衡，碳水循环更多是帮助训练者在热量受限时维持训练表现与饮食依从性的工具，而非独立的"燃脂开关"。

## 具体建议

- 以周为单位规划：例如 4 个训练日为高碳日（每公斤体重 4-6g 碳水），2 个休息日为低碳日（每公斤体重 2-3g），1 天自由调节；
- 蛋白质保持恒定：每公斤体重 1.6-2.2g，不随碳水波动，以保护肌肉；
- 高碳日优先安排在腿日、大肌群日或高强度日；碳水以米饭、燕麦、红薯、水果等复合来源为主；
- 低碳日不必"零碳水"，用蔬菜与适量粗粮维持饱腹与训练恢复；
- 每 4-6 周复盘体重、围度与训练表现，及时调整高低碳日的碳水配比。
